# Sine Wave Audio Generator

**Онлайн-генератор чистого синусоидального сигнала 0–20 000 Гц**  
с живым воспроизведением, логарифмической/линейной шкалой и сохранением в высококачественный PCM WAV или MP3.

[Открыть генератор →](https://volkovhl.github.io/sine-wave-generator/)

---

### Возможности

- **Частота**: 0 – 20 000 Гц (шаг 0,1 Гц)
- **Две шкалы**:
  - **A** — логарифмическая (удобно для слуха)
  - **B** — линейная
- Точный ввод частоты вручную
- Кнопки точной подстройки ±0,1 Гц (с ускорением при удержании)
- Живое воспроизведение через Web Audio API
- Длительность файла: **0,1 – 1000 секунд**
- Скачивание:
  - **PCM WAV** — 96 / 192 / 384 кГц, 16 / 24 / 32 бит
  - **MP3** — 64 / 128 / 256 / 320 кбит/с
- Плавное нарастание и затухание (fade) в файлах
- Полностью работает в браузере, адаптивный интерфейс

---

### Как пользоваться

1. Откройте [генератор](https://volkovhl.github.io/sine-wave-generator/)
2. Выберите частоту:
   - Ползунком (тяните вверх-вниз)
   - Вводом точного значения
   - Кнопками **+0.1** / **−0.1**
3. Переключайте шкалу кнопками **A** (логарифм.) / **B** (линейная)
4. Нажмите **▶ Включить** для прослушивания
5. Установите нужную длительность
6. Нажмите **⬇ Файл** → выберите формат и параметры → **Скачать**

### Формула сигнала

\[ y(t) = A \cdot \sin(2\pi f t) \]

где:
- \( A \) — амплитуда  
- \( f \) — частота (Гц)  
- \( t \) — время
